# recsys

Пробовал два подхода.

## LightFM

Основной подход, который пошёл в финальные сабмиты. Обучал три отдельные модели на разных сигналах (лайки, фавориты, просмотры >60 секунд) и объединял рекомендации по приоритету: сначала фавориты, потом лайки, потом просмотры. Гиперпараметры тюнил через Optuna.

## SASRec

Решение на тестовое, чтобы проверить гипотезы и посмотреть подход — что учёт последовательности событий и их типа даст что-то сверху. Написал на чистом PyTorch, код местами не оптимальный. Пробовал добавить контекст событий (тип + время просмотра в бинах) и GBCE лосс из gSASRec. В итоге в финальные сабмиты не пошло
