# recsys2

Двухэтапный пайплайн - кандидаты от CF-моделей, ранжирование через CatBoost

## Ноутбуки

**candidates.ipynb** — обучает ALS, BPR, KNN, EASE на матрице взаимодействий, собирает кандидатов и считает фичи для ранкера

**ranker.ipynb** - обучает CatBoostRanker

**data_utils.py** - общий вспомогательный код для ноутбуков

## Кандидаты

Данные разбиты по дням: train — дни 1–5 (метка день 6), val — дни 1–6 (метка день 7), test — дни 1–7

Позитивное взаимодействие: лайк, добавление в избранное или просмотр дольше 60 секунд. Для матрицы используются веса: favorite=6, like=5, watch_time — от 1 до 4 в зависимости от длительности

Для каждого сплита обучаются 4 модели:
- ALS 
- BPR 
- KNN
- EASE

Каждая модель даёт 80 кандидатов (KNN 50), все объединяются, кандидаты, с которыми взаимодействовал пользователь, убираются

Для каждой пары (user, item) сохраняются скоры и ранги всех моделей + агрегаты: `n_models_recommended`, `best_rank`, `mean_rank`, `rank_std`, `n_models_top50`, `pop_score`. ALS, BPR и EASE скоры ещё нормализуются по пользователю

## Фичи

Пользовательские фичи - считаются за последние 1/2/3 дня:
- кол-во позитивных и всех событий
- кол-во уникальных айтемов
- средний timespent
- доля лайков, фаворитов среди взаимодействий
- тренд активности (день vs среднее за 3 дня)

Фичи айтемов — аналогично за 1/2/3 дня:
- кол-во позитивных событий и уникальных пользователей
- средний timespent
- доля completion/skip/like/fav
- рост аудитории и тренд (сравнение первых и последних дней)
- ранг по популярности

## Ранкер

CatBoostRanker, loss=YetiRank, 1000 итераций с early stopping. Остановился на 890-й итерации, NDCG на val = 0.722

По SHAP больше всего влияют BPR и ALS скоры (особенно нормализованные) и `i_positive_events_last_1_days`

Финальный сабмит - топ-20 по скору ранкера. Пользователи без кандидатов (их 33) заполняются популярными айтемами с фильтрацией айтемов, с которыми взаимодействовал пользователь
